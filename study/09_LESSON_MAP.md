# 09 — Proposed lesson map (~95 lessons)

This is a **content map**, not written lessons. 52 weeks is the cadence. Lessons are the intellectual content. A week may hold one major lesson plus reading, cluster study, discussion, and a charge.

**The Walk and The Intensive use this same list.** Intensive assigns more pages, more drill, and a longer charge.

Target: 12–18 lessons per course, ~80–100 for the year. This map: **95**.

IDs match later courseware (`L-1.01` = Course 1, lesson 1).

## Standard lesson core (when a lesson is later written)

Required: title, central principle, key Scripture, cluster, context, terms **the source uses**, distinctions, core teaching, source questions, written charge, related Aletheia book if the leaflet names one.

Optional: discussion, memory verse, short knowledge check.

Do not fill empty fields.
