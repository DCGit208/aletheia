# 02 — Scripture study matrix

Every printed citation in Aletheia Libraries 1, studied in the KJV and as part of the leaflet’s cluster. Compressed prints are recorded as printed.

**Columns used below:** Doctrine → Source claim → Scripture (printed) → Context studied → How the cluster works → Terms → Distinction → Chronology → Course → Book section.

Citation key: `20:1015` = 20:10-15; `3:89` = 3:8-9; `Heb.914` = Hebrews 9:14; `Gal. 4:57` = 4:5-7; `Rev. 20:46` = 20:4-6; `22:1819` = 22:18-19.
