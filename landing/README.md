# Aletheia World parent site

Static parent site for [aletheiaworld.org](https://aletheiaworld.org). It names the charge — **Mathēteuō** — and invites people into **Aletheia**, the platform. It is not a second LMS.

The PWA remains on `app.aletheiaworld.org` / `aletheia-world.web.app`. This folder deploys only to Firebase Hosting site **`aletheia-landing`**.

## Pages

| Path | File |
| --- | --- |
| `/` | `index.html` |
| `/matheteuo` | `matheteuo.html` |
| `/foundation-school` | `foundation-school.html` |
| `/school` | redirects to `/foundation-school` |
| `/publications` | `publications.html` |
| `/about` | `about.html` |

Primary CTAs go to `https://app.aletheiaworld.org`. Nav: Home · Mathēteuō · Foundation School · Publications · About + Enter Aletheia.

`robots.txt` and `sitemap.xml` are generated with the pages.

## Preview locally

```bash
npm run build:landing
npx --yes serve landing -p 4173
```

Then open `http://localhost:4173`.

## Deploy (Achu, after review)

Do not deploy from an unreviewed PR. From the repo root, with Firebase CLI signed in as an owner of project `aletheia-world`:

```bash
npm run build:landing
npx -y firebase-tools@latest deploy --only hosting:aletheia-landing
```

That command uploads this folder to site `aletheia-landing` (apex `aletheiaworld.org`). It does **not** replace the PWA on `aletheia-world` / `app.aletheiaworld.org`.

The PWA is still:

```bash
npm run deploy:hosting
```

which deploys only `hosting:aletheia-world`.

## Rebuild pages

Header, footer, mission string, enrollments, and page copy are generated by `landing/build.mjs`. After editing that file:

```bash
npm run build:landing
```

Fonts are SIL Open Font License (Fraunces, Source Sans 3), self-hosted in `fonts/`.
